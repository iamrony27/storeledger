Common Questions

Frequently Asked Questions

Everything you need to know about Store Ledger and data ownership.

Is Store Ledger really 100% free with no forced subscriptions? expand_more
Yes! Store Ledger is open-source under the MIT license. There are no monthly subscription fees, paywalls, or in-app ads. All offline features work indefinitely without payment.
Do I need an internet connection to use the app? expand_more
No. Store Ledger is completely offline-first. You can add customers, record credits/debits, view analytics, and generate PDF statements without any internet connection.
How does the Bring-Your-Own Supabase cloud sync work? expand_more
You create a free Supabase project and provide the Project URL and Anon/Publishable Key. Store Ledger syncs directly to your PostgreSQL database with Row Level Security, ensuring you retain 100% ownership of your records.
Can I switch currencies or use fractional decimal amounts? expand_more
Yes. Store Ledger supports 9 global currencies (INR, USD, EUR, GBP, BDT, AED, SAR, CAD, AUD). You can toggle decimal (.00) precision on or off anytime. Data is stored in exact minor units (paise/cents) so no precision is ever lost.
How do I back up my ledger data safely? expand_more
You can create encrypted, SHA-256 verified snapshot backups directly from Settings. Backups can be shared via WhatsApp, Google Drive, email, or saved to your device's external storage.
